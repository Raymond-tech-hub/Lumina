explain this file
find where login is handled
fix this bug
add a new screen for settings
run the app and tell me why it crashes
review my changes
write tests for this module
clean up this function
where is the quiz data coming from?
A good mental model is:

Ask questions when you want understanding.
Ask for changes when you want implementation.
Ask for review when you want risks and bugs identified.
Paste errors when something fails and I’ll trace them.
